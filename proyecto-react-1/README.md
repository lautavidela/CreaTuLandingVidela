# CreaTuLandingVidela

## 📌 Descripción
Aplicación web de tipo **e-commerce** desarrollada como entrega final del curso de **React en Coderhouse**.  
Permite visualizar productos, ver el detalle, agregar al carrito y finalizar una compra generando una orden en **Firebase Firestore**.

---

## 🚀 Tecnologías utilizadas
- React
- React Router DOM
- Context API
- Firebase Firestore
- JavaScript
- HTML
- CSS

---

## 🛒 Funcionalidades
- Listado y detalle de productos desde Firestore
- Filtrado por categorías
- Carrito de compras con estado global
- Selección de cantidad con control de stock
- Generación de orden de compra
- Visualización del ID de la orden
